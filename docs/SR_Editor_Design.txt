设计一个静态网页，主要功能是根据用户的选择情况，生成一个json文件，并提供下载
该网页包含2个部分
左侧显示需要的功能
右侧显示一个flow模块的编辑

左侧的功能区
1. 加载一个本地的json文件，请根据功能定义文件格式
2. 左侧提供给客户，需要哪些功能

左侧的flow模块区
1. 加载一个本地的json文件
2. 显示一个大的 + ，用户点击后，显示一个列表和另一个 + 
这样循环，直到用户不再点击 +，列表来自于步骤1的本地json的数据

该json的格式是一个json数组，数组里面的一个item大概是下面的样子
每个item都有"moduleName",该值就是该模块的唯一名字值，所有模块不能重复
每个item都有"moduleDispalyName",该值就是显示在上面步骤2种列表的一个item的名字
每个item都有"description",该值描述该模块的作用
每个item都有"dependence",该值描述该模块的依赖
每个item都有"input",该值为一个json object
每个item都有"result_description",该值的key表示该模块有可能的error code，value表示该error code的描述
{
	"moduleName": "refurbish",
	"moduleDispalyName": "refurbish task",
	"description": "refurbish the device on a specific USB port",
	"dependence": "1. The device type information(iOS or Android) comes from the module getUsbInfo in the database. 2. android device, the fdbox723.apk already install by module installApps",
	"input": {
		"customDataTag": "iosRefurbishTask",
		"customizeIpsw": {
			"ipswFolder": "",
			"customizeIpsw": {}
		},
		"_customizeIpswSample": {
			"ipswFolder": "c:/dmg",
			"customizeIpsw": {
				"iPhone14,2": {
					"ipsw": "iPhone14,2_15.1.1_19B81_Restore.ipsw",
					"dmg": "018-98872-002.dmg"
				},
				"iPhone14,3": {
					"ipsw": "iPhone14,3_15.1.1_19B81_Restore.ipsw",
					"dmg": "018-98883-002.dmg"
				}
			}
		},
		"retryTimeWhenFail": "2",
		"retryInterval": "1",
		"moduleTimeout": "3600",
		"_comment": "1. timeout and retry, which will appear first and which will be used 2. _port parameter come from API interface"
	},
	"result_description": {
		"-1": "failure, exception",
		"0": "success, refurbish device success",
		"1": "failure, refurbish device failure",
		"2": "not support android"
	}
}

3. 用户双击模块后，弹出一个对话框
	显示"moduleName",不可以编辑
	显示"moduleDispalyName",不可以编辑
	显示"description",不可以编辑
	显示"dependence",不可以编辑
	显示"result_description",不可以编辑
	显示"input",可以编辑，根据json object的格式，显示对应的表格，让用户编辑
	
4. 在网页的最上面，显示2个按钮，导入和导出
   导出： 把上面的左侧的功能区和右侧flow区域的内容，组织成一个合理格式的json文件，并让用户下载
   导入： 导入上面的json文件，形成网页内容
